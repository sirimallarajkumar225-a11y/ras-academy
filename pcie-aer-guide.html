PCIe Advanced Error Reporting (AER)

Advanced Error Reporting (AER) is a PCI Express capability used to report and manage certain PCIe error conditions. Reporting and recovery behavior depends on device, topology, software and platform implementation.

Error categories

PCIe AER distinguishes classes such as correctable errors and uncorrectable errors, with uncorrectable events further classified by severity. Classification provides context, not a standalone root-cause conclusion.

Investigation approach

  • Correlate logs by time and reporting component
  • Review the topology and relationship between devices
  • Distinguish isolated events from recurring patterns
  • Consider recent changes and workload context
  • Document impact, evidence and next steps separately

Linux tools

Read-only tools such as lspci and kernel log viewers can help inspect reported information on systems where you have authorization. Use platform documentation to understand available interfaces and their limitations.
