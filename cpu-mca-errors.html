CPU Machine Check Architecture (MCA)

Machine Check Architecture (MCA) provides mechanisms for reporting hardware error conditions in processors and related platform components. The details of records, banks and interpretation depend on processor family, firmware and operating system support.

What machine-check records represent

Records may contain status fields and, where applicable, additional context such as address or syndrome information. These fields must be interpreted against the relevant architecture documentation; a field value should not be treated as a diagnosis in isolation.

Firmware-first and OS reporting

Platforms may use firmware-mediated reporting or operating-system handling pathways. ACPI interfaces and system configuration influence how events are surfaced. Reporting paths can differ across platforms.

Evidence correlation checklist

  • Preserve the original record and timestamp
  • Identify reporting source and severity
  • Correlate with kernel logs and platform event logs
  • Review workload and system state
  • Record uncertainties and follow-up actions
